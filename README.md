# Nt.Demo.AwesomeWarehouse

***Feladat: Raktáralkalmazás***

*Tegyük fel, hogy a raktárprogram alkatrészeket kezel, amelyek az alábbi attribútumokkal rendelkeznek:*

-   *Azonosító*

-   *Név*

-   *Egységár*

-   *Leírás*

-   *Tömeg*

*A következő funkciókat szeretnénk látni:*

-   *Termék hozzáadás, módosítás, törlés*

-   *Raktárkészlet listázása, kivétel, bevétel*

-   *Statisztikák:*

-   *Raktár össztömege*

-   *Raktár összértéke*

-   *Legtöbb tételű termék*

-   *Legnagyobb tömegű termék*

***Extra feladat:***

*A forintban tárolt árak jelenjenek meg* ***aktuális EUR középárfolyamon*** *is. A használható források*

-   az MNB webszolgáltatása VAGY

-   *a [frankfurter.dev](http://frankfurter.dev/) API.*
